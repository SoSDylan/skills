# CrewTraka help style

Apply this reference to every new or revised CrewTraka help article, including collections that already contain articles. This reference is the reusable editorial source distilled from approved CrewTraka articles.

## Approved content

- Preserve the substantive meaning and article-specific details of user-approved content when active code supports them.
- Revise wording and organization as required by the ASD-STE100 checklist and this reference.
- If active code contradicts a substantive approved claim, block the article and report the exact conflict.
- Use approved articles from other topics only as editorial examples. Do not transfer their product claims.
- Correct grammar, punctuation, and inconsistent terminology. Use complete sentences where ASD-STE100 rule S6 requires them.

## Task focus

CrewTraka help articles assume an authenticated dashboard context when the introduction or prerequisites establish that context.

- Start each procedure with the first task-specific action.
- Include sign-in only when authentication is the task, the authentication method changes the workflow, or the starting state would otherwise be unclear.
- Keep roles and permissions in **Before you start** unless the reader must take an action to obtain or select them.
- Use one customer-facing term for each object throughout an article. For an object without an interface label, verify the term against active behavior and user-approved content recorded for the run.

## Support policy

Link every support direction only to [CrewTraka support](https://www.crewtraka.com/support). Do not include a support email address or phone number. This stable link overrides contact details in approved articles, reference articles, interface copy, and code.

## Audit

Confirm that:

- each procedure starts with the first task-specific action;
- each sign-in instruction meets an authentication exception;
- roles and permissions are prerequisites unless the workflow requires an action;
- each object has one verified customer-facing term;
- grammar and punctuation are correct, and paragraphs and numbered steps use complete sentences;
- every support direction uses the CrewTraka support link; and
- no support email address or phone number appears.

Scan every target article for URLs, support references, email addresses, and phone numbers. Read each match in context and correct every policy violation.
