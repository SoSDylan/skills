# Product

## Register

product

## Users

Developers who use Pi and other agent harnesses from a terminal. They need reusable skills and extensions that support focused coding workflows without obscuring the work with unnecessary interface noise.

## Product Purpose

Provide dependable agent skills and Pi extensions that are easy to install, understand, and operate. Success means developers can delegate work, inspect progress, and trust results without learning custom workflow conventions for each package.

## Brand Personality

Precise, restrained, and trustworthy. The interface should feel native to expert terminal workflows and should keep implementation details available without making them the default focus.

## Anti-references

Avoid decorative dashboard patterns, verbose raw JSON, unexplained custom controls, noisy status displays, and output that competes with the child agent's final response.

## Design Principles

1. Show progress at a glance, then make detail available on demand.
2. Prefer familiar terminal conventions over invented visual language.
3. Keep status understandable without relying on color alone.
4. Preserve evidence and diagnostics while keeping the default view compact.
5. Make extension behavior predictable across normal, error, and cancellation states.

## Accessibility & Inclusion

Use text and symbols together for important states. Respect terminal width, configured themes, and user keybindings. Keep content readable without animation and avoid color-only distinctions.
